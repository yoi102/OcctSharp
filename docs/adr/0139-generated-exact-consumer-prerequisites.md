# ADR-0139: generated exact consumer prerequisites

Status: Accepted for authorized CH; implementation and delivery separately gated.
Date: 2026-10-12.

The locked production Cadoryx application requires public interfaces which exist
only in the audited SDK26 source input. Its complete application and tests must
remain the acceptance consumer. Removing calls or selecting a simpler application
would not satisfy the authorized downstream acceptance.

Emit these bounded prerequisites through exact-consumer-v1, with fixed SDK header
hashes, template source hashes, strict output roots and manifest ownership. Human
algorithm policy remains identified as supporting templates. Do not award new
OCCT StableIds merely for moving support code into templates. Modeling keeps the
legacy interop assembly owner; facade APIs retain their existing module boundary.

Serialized reference/occurrence payloads belong to the existing FeatureResult
owner and registry. Stored import establishes decoded membership, not original
capture or composed modeling history. Explicit occurrence selection is required
when identity occurs along multiple paths. Budgets and failure atomicity remain
enforced. Guided offset preparation uses the existing copied-graph contract;
unadmitted private copy/history-domain proof APIs are excluded.

Extend ADR-0046 with viewer-owned source IDs. A creation entry owns a detached
source topology and effective styles, while each independently selectable
instance retains the source snapshot. Releasing creation entries cannot invalidate
existing instances. Selection maps only actual native original/copy relations;
refresh requires unchanged original identity, topology membership and placement.
Instance style edits detach graphics and preserve independent mutable drawers.
Sources do not cross viewers or owner threads. Existing registries and ABI layout
categories remain; new APIs require ABI1.117. Owner destruction marks managed
sources removed and releases both creation and instance maps.

Numerical inspection remains the existing SC-067 infrastructure. The discovered
offset-basis knot defect is repaired without fitting, changing parameter domains
or relaxing any numerical acceptance assertion. This is not declaration credit.

Required validation: deterministic generation, actual native/managed builds,
runtime/error/lifetime and layout tests, original full application compilation and
tests, real long workflows/desktop pixels, repeatable performance with timing
limitations, exact packages and complete local delivery gates. External gates
remain explicit NOT RUN until independently executed.

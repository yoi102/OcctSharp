## Decision

Build the private `.12` candidate from all 950 terminal `.11` source hashes,
not the current Preview.34 checkout. Keep the viewer's `AIS_ColoredShape`
presentation registry, existing presentation IDs and native selection owners.
A private subclass connects its computed graphics to a viewer-owned source;
selection still belongs to the individual instance. Style mutation detaches
only that instance's graphics and uses its independently owned mutable aspects.
The subclass remains compatible with existing transform, selection, overlay,
manipulator and appearance paths; those paths need actual bridge tests.

`CreateSource(Shape)` and `CreateSource(XdeLabel)` take a native topology copy
and retain original-to-copy correspondence from `BRepBuilderAPI_Copy`.
Rendering operates on the copied topology. The retained original graph is
used exclusively to prove and return original selection identities. Matching
requires native TShape partnership and exact equality of all twelve transform
coefficients; ambiguous or missing correspondence rejects without guessing.
Subshape editing accepts original source members and resolves the copied
member before changing the instance's drawer.

Effective XCAF surface/curve/visibility/material styles are rebuilt on a private
document and exact copied subshape labels. Material metadata and mutable
shading/line aspects belong to the snapshot or individual instance. Imported
hierarchies, textures, material inheritance and PBR rendering still require
stronger verification than the constructed box fixtures.

Sources are parent/thread bound. Their globally non-reused native creation IDs
remain in the owning viewer; releasing a source creation entry prevents new
instances while existing instances retain the snapshot and topology map.
Clearing source entries has the same rule. Removing instances releases their
retained source; viewer disposal clears presentations, retained instance maps
and creation entries. No native pointer, XCAF label or caller-owned mutable
drawer is exposed by the managed source object.

### Inherited fallback appearance

The private XCAF presentation specialization inherits ordinary AIS default material and distinct wire/free/unfree boundary colors. Fallback surface/curve values keep their author-override flags unset; marking them authored would mutate ambient even without a document assignment. Explicit author colors/materials are applied by the standard XCAF dispatcher. Default curves are restored only for exact copied style members with no curve/material assignment; synthetic style groups require consistent exact copied members or reject. There is no geometry tolerance or topology rebinding heuristic. The public API, ABI1.76, bridge0.84.0, original-source copy map, shared-instance ownership and override lifetimes remain unchanged.

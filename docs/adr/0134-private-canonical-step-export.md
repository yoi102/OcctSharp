# ADR-0134: private canonical multi-file STEP export

Status: Accepted within the authorized BL–BQ scope.

Use one exact context-bound selected root list, one shared native label clone map and an independent geometry graph. Keep writer/session/maps private. A hash-pinned SDK source copy is transformed and emitted by the generator to use canonical ordinal filenames and transfer complete private settings to each external model before computation. This addresses two proven SDK boundary gaps while retaining original assembly/metadata algorithms and copyright. Preserve only explicitly supported names/colors/layers; copy no arbitrary reference-bearing document attributes.

Preflight the complete flat output set before SDK writes. Keep native writes inside a private stage, validate every output and hash, then copy into an adjacent stage and publish by one directory rename. Reject existing targets and changed/reparse paths; failures clean this operation's owned stages. No stream/BVH/work session or borrowed map is returned. AP203/AP214 and bounded precision are copied diagnostics, not fidelity/error certificates.

Keep the cohesive private writer as one independent generated translation unit with generator-enforced finite bounds of 6000 native lines and 1000 header lines, pinned raw hashes and no implementation inclusion. The manual source layout checker remains unchanged. Full internal source is support code and does not imply public migration credit. Only exact used operations gain StableId credit. Preserve raw source hashes and deterministic transformation guards.

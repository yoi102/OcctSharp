# ADR-0119: initialized assembly and copied validation

Status: Accepted (2026-10-10).

TM036 extends the closed workflow catalogue to private BRepBuilderAPI edge/wire
receivers, mixed edge/wire assembly and explicitly configured BRepCheck validation.
An empty edge receiver is used only inside one native call and is initialized
before status/result access. Curve/surface inputs are deep copied under retained
managed handles. Endpoint/range errors retain SDK diagnostics without publishing
partial topology. Geometry mutation while copying remains caller synchronized.

Mixed topology inputs are copied as a single graph, preserving existing sharing.
SDK geometric coincidence is allowed inside fresh construction, with no inferred
source history. Stop at the first disconnected input. Completed topology requires
BRepCheck validity; every shape query returns another geometry-deep copy.

Piecewise linear UV pcurves share one call-private surface through edge, wire and
face construction. Separate copies do not establish pcurve identity. The 3D
representation is SDK approximation with explicit tolerance, degree and segment
limits. A face requires explicit repeated UV endpoints and a closed valid wire.
Trimming domains and source topology correspondence are not inferred. A separate
Face(surface) request succeeds only with valid resulting pcurve representation;
it does not silently repair or rebind support geometry.

Validation owns a complete copy and records selected exact/parallel flags plus
invalid exact members. The SDK exact flag applies to SameParameter edges only.
Wire-area analysis selects a wire in the exact copied face and initializes face,
precision and readiness before checking. Preserve its status mask: false with
failure bits is not a successful negative result.

Output tokens use typed registry leases/SafeHandle ownership. Copied diagnostics
survive release. No builder, borrowed topology or mutable tool is exposed. Keep
the single bridge, old generated bytes, exact accounting and full delivery gates.

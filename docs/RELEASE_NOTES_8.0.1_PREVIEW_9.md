# OcctSharp 8.0.1-preview.9 release notes

Preview.9 completes Batch L as one 24-capability occurrence-aware digital mock-up
bounds, broad/exact-phase, filtering, clearance/contact/penetration/containment,
traceability, incremental, review, lifetime, and clean-package wave. It remains an
experimental Windows x64 package for .NET 10 and OCCT 8.0.1.

## Added

- Stable order-independent pair IDs, caller shape inputs, and world-located XDE leaf-
  occurrence expansion with copied definition and occurrence-path traceability.
- Finite copied AABB and OBB values plus a native-local sweep broad phase, explicit,
  same-definition, and adjacent filters, and complete terminal pair matrices.
- Exact minimum distance and owning support witnesses; clearance, contact, penetration,
  inside/contains/coincident classification; overlap volume and owning issue topology.
- Copied face/face, edge/edge, mixed interference groups, bounded self-checks, finite
  tolerance/robustness policies, aggregation, diagnostics, timing/count summaries, and
  independently cloned incremental reruns.
- Severity-colored viewer review with isolate/show/select/fit/keyed-screenshot operations,
  real STEP/XDE and real HWND evidence, source/document disposal, and a clean 62-DLL
  package-consumer workflow.

## Ownership and compatibility

Bnd/BVH, BRepExtrema, BRepClass3d, BRepAlgoAPI/BOP/IntTools, explorer, map, and progress
state stays native-local. Inputs are borrowed only during synchronous calls. Pair,
bounds, witness metadata, diagnostics, timing, and traceability values are copied; support
and issue topology is independently owning; XDE labels and viewer presentations retain
their document/viewer/thread parent rules. Package identity is `8.0.1-preview.9`, native
ABI is 1.54, bridge implementation is 0.62.0, configuration schema is 1.12, and managed
assembly/file identity remains `0.1.0.0`.

SC-048 reconciles exactly ten directly used blocked OCCT 8.0.1 stable IDs. The other 646
blocked declarations in the Batch L preparation audit were not bulk-marked manual.

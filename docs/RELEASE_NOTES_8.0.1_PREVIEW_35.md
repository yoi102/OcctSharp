# OcctSharp 8.0.1-preview.35

Windows x64 / .NET 10 / OCCT 8.0.1. Native ABI 1.79, bridge 0.87.0.

Batch AK connects private STEP/IGES readers to one transfer epoch and detached
record/process/diagnostic snapshots. Distinct session-bound model numbers and
transfer-map indices reject cross-domain inputs before mutation. Results retain
exact shape/entity identity and remain usable after reader and source-file disposal.
Native record order and duplicates, no-result state and diagnostic buckets remain
explicit. Functional shape binders copy container/check storage for append,
replacement and messages; typed reads validate topology before casting.

The exact audit admits 78 of 163 candidates plus 11 newly generated support
operations. Twenty-five Emitted and one Manual dependencies are reused; 85
candidates remain deferred with concrete SDK/lifetime/workflow reasons. There is
no claim of full OCCT migration. Prior generated declarations and APIs are retained.

Unsafe SDK root/recorded index lookups, SelectResult, ResultOne/CheckListOne,
recursive public graph/record paths, absent BRepCheck, external actors/contexts
and finder-process writer mutation remain excluded. See the
[contract](BATCH_AK_TRANSFER_RECORDS.md) and [admission matrix](BATCH_AK_TRANSFER_RECORDS_ADMISSION.json).

This is a local engineering candidate. STATUS and the hash-bound batch-ak evidence
own actual delivery gates. Hosted CI, signing and public publication are separate
and were not authorized as part of this migration round.

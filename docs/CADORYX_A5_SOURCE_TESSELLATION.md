## Problem and implementation

Full source graphics spend most measured work in native tessellation. The selection-cache experiment was made correct through explicit sensitive-entity ownership transfer and recursive Group/Wire cloning, but its MiniPC3 Display benefit was only1.647percent. It is not adopted in .15.

The new owned mesh helper obtains the same configured BRepMesh factory operation, absolute deflection computed by StdPrs from the existing drawer, and the same deviation angle. For the incremental mesher it sets only that operation's InParallel flag. Global factory defaults and precise BRep/inspection tolerances are unchanged. A nonincremental configured factory retains its original operation. Mesh work is synchronous and touches only the existing detached viewer topology; OpenGL presentation work remains on its existing owner thread.

Shared shaded graphics prepare the owned source before connecting its presentation. An independent shaded override first follows native own-deflection invalidation, then prepares its owned shape before the existing AIS builder. Wireframe behavior and the exact original AIS selection builder remain unchanged. There are no new public exports, manual generated-code edits or ABI changes.

# Batch AK: private transfer records, process collections and diagnostics

Historical frozen audit plan. The completed outcome and all deferred reasons are
in the [contract](BATCH_AK_TRANSFER_RECORDS.md) and
[admission matrix](BATCH_AK_TRANSFER_RECORDS_ADMISSION.json).

Execution baseline: locally delivered Preview.34 / Batch AJ, once STATUS records
completion. The [candidate inventory](BATCH_AK_TRANSFER_RECORDS_CANDIDATES.json)
freezes **163 exact Blocked public declarations across 14 families**
against AJ's fresh inventory/discovery hashes. This is audit scope, not admission,
implementation or a migration quota. One larger coherent batch connects file
transfer to retained records, safe result/check snapshots and identity-safe queries.

## Planned outcome and order

| Stage | Useful result and admission gate |
|---|---|
| SDK audit | Read pinned implementations and linked symbols; freeze each selected overload and each existing supporting disposition. Explicitly retain AI's failed Debug/index evidence. |
| Private process lifecycle | A reader-owned transfer process with serialized access, bounded state transitions and parent/epoch retention; expose no external mutable native process or callback. |
| Record/binder collections | Owning detached containers of retained entity/shape/record values with exact model/transfer identity, explicit duplicates/order and independent result lifetime. |
| Result and check snapshots | Safe recorded/mapped entity/shape lists and message/check statistics, with separate model-number and transfer-index domains. Empty/failure/status remain distinct. |
| Public integration | STEP and IGES file -> one transfer epoch -> record/process/binder snapshots -> shape/entity/check inspection -> disposal -> surviving results and repeat-query consistency. Execute one shared public-only workflow in Runtime and both consumers. |
| Delivery | Fresh exact inventory/delta, preservation, full Release/Debug and actual Debug native, cold regeneration, ABI/lifetime/module/API/export checks, 14 packages, both clean consumers and hash-bound local release/synchronization. |

## Explicit boundaries

AI's unsafe root lookup mixes model/map indices. Its recorded EntityFromShapeResult
modes use the wrong inner-sequence index and failed actual Debug native. Neither
becomes an unconditional target here; use source-backed safe snapshots or defer.
Recursive TypedSharings and external actors/callbacks remain excluded. Validate
indices, epoch and exact membership before native access; do not infer identity
from geometry or automatically rebind topology. A header declaration does not
prove symbol availability, initialization or detached mutable storage.

Test nonempty STEP/IGES records, empty/no-result/failure records, wrong index
domains, foreign lookalikes, duplicates, overflow, status/check publication,
parent/source disposal, mutation/epoch retention and SafeHandle release races.
Count only actual Blocked-to-Emitted transitions; reused Manual/Emitted supporting
operations stay separate. Record concrete deferred reasons. Complete this whole
outcome before further migration. [WORKFLOW](WORKFLOW.md) defines execution policy;
[ROADMAP](ROADMAP.md) owns later priorities. Subsequent geometry workspaces or
parser/SDK fixes require a demonstrated consumer gap rather than fixed batch counts.

# OcctSharp 8.0.1-preview.16

Local-only Batch Q preview. No NuGet publication or GitHub push is part of delivery.
Native ABI 1.60, bridge 0.68.0, OCCT 8.0.1, schema 1.13; assembly identity stays 0.1.0.0.

## Source-bound repair workflows

The [40-capability wave](BATCH_Q_SHAPE_REPAIR_TOPOLOGY_GAP_INVENTORY.md) adds copied
topology/defect snapshots, tolerance distributions and owning free boundaries; typed
selected/protected multi-stage repairs; wire, face, shell, solid, sewing, division,
hole/location normalization, explicit topology edits and protected unification;
composed history, verified budgets, atomic acceptance, shared-definition publication,
STEP/IGES delivery, real-viewer defect selection and portable recipes/audit records.

Twenty typed operation contracts compose as one ordered `RepairPlan`. Every stage
works on a private copy. Failure releases intermediate results and records later
stages as skipped. `Accept` returns an independent Shape owner exactly once; disposing
the preview or source does not invalidate that accepted shape.

The STEP style-recovery path now transfers product roots before isolated styled
targets. This preserves shell-based shared assembly geometry while retaining the
existing disconnected-presentation color recovery.

## Architecture and compatibility

The existing twelve module assemblies, facade and one Native DLL remain. Repair
contracts/operations belong to Modeling; XDE/exchange/viewer composition belongs to
the facade. Nine cohesive native files use the existing registry/error boundary,
adding one repair-result live set with a matching release. All 51 manual translation
units are independently compiled; 35 private headers are independently checked.
SC-054 records 106 exact directly used formerly Blocked declarations, not every
overload in the audited classes. Fourteen additive C exports use copied buffers and
opaque ownership; no OCCT container or callback crosses the ABI.

## Contracts and limitations

- Source selectors include snapshot ID, revision and zero-based topology index.
  They do not promise persistent identity through arbitrary splits or merges.
- History represents unknown/deleted/ambiguous mappings explicitly. Required
  selections and protected shapes must resolve uniquely or the stage rejects.
- All linear thresholds use the declared input unit, with squared/cubed units for
  area/volume. An unavailable required budget is not zero drift and blocks acceptance.
- Wire gap reports measure each adjacent pair in 3D and, where pcurves exist, 2D.
  2D residuals use UV units; their OCCT status uses a surface-dependent parametric
  threshold, not a document-length comparison. Missing support is explicitly unavailable.
- Hole/small-feature removal and topology simplification are opt-in modeling changes.
  Shell normalization establishes consistent face uses; solid normalization also
  establishes the bounded-material orientation. Continuity division accepts parametric
  C0/C1/C2/C3/CN, not G1/G2.
- XDE publication updates a shared definition once in one transaction, retains
  occurrence placements, and rejects ambiguous metadata mapping or stale geometry.
  STEP/IGES preserve only their supported metadata; a recipe is not a CAD-file format.
- Viewer review requires an existing real HWND/context and its owner thread.
  No headless renderer, D3DImage, cross-platform proof or new physical DLL is included.

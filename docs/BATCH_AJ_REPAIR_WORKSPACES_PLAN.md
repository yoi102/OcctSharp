# Batch AJ: coupled repair workspaces and exact replacement history

Execution baseline: locally validated Preview.33 / Batch AI. The
[candidate inventory](BATCH_AJ_REPAIR_WORKSPACES_CANDIDATES.json) freezes **188
Blocked public declarations across 16 families** against the fresh AI exit
inventory and discovery hashes. These are audit candidates, not admitted bindings,
a migration quota or a promise that all native constructors can be copied safely.
AJ implementation is authorized and under delivery validation. The
[AJ contract](BATCH_AJ_REPAIR_WORKSPACES.md) and admission matrix record the actual
136 admitted candidates, 52 deferred candidates and one new prerequisite.
This plan preserves the original audit scope; STATUS owns current results.

## One larger useful outcome

Connect imported or authored topology to detached wire diagnostics, coupled repair
workspaces, face/shell repair, exact replacement history, validation and STEP/IGES
roundtrip. Reuse AI owning shape sets and exchange sessions. Group the related
stages into one batch, with one shared public-only acceptance workflow executed
by Runtime and both facade/direct-module package consumers.

Existing Manual/Emitted factories, configuration, inspection and context methods
are supporting dependencies. Freeze their exact IDs and current dispositions in
the AJ admission matrix after the SDK audit. Count only actual disposition changes
as migrations. Do not duplicate stable-ID accounting merely because an existing
native operation is reused by another workflow.

## Ownership and identity decisions before generation

- Read pinned SDK implementations and inspect linked symbols for each selected
  overload. Audit initialization, mutation and the complete required dependency
  path; a header declaration alone does not prove a usable binding.
- Own the repair receiver and its ReShape context privately. Retain or invalidate
  a workspace by a documented parent/epoch rule. Do not accept arbitrary maps from
  another source or receiver. Validate every input before mutating the epoch; if
  an exception leaves native state unproved, retire the receiver.
- Copy map/list/sequence storage; shape values still share TShape unless a
  separately audited non-destructive/deep-copy operation is used. WireSegment and
  WireData copy constructors may share mutable storage. Prove detachment or defer
  them. Preserve the distinctions among IsPartner, IsSame and IsEqual when
  selecting key membership, location and orientation semantics.
- Nested maps need typed key/value contracts, duplicate-key rules, list order,
  maximum counts and success-only multi-output publication. Native map traversal
  order is not a stable serialized index unless a contract defines one.
- Never infer replacement by proximity. Expose unchanged/removed/replaced,
  split/merge and unavailable evidence separately. An ambiguous result remains
  ambiguous; no automatic selected-topology rebind is permitted.
- Exclude borrowed references, mutable external contexts, callbacks, unbounded
  workspaces and unproved recursive paths. Scope changes need explicit concrete
  reasons in admission/deferred rows. Record ownership changes and an accepted
  ADR before emitting a new workspace category.

## Acceptance and delivery

Use meaningful fixtures for reordered/reversed wires, free and nonmanifold edges,
small edges/gaps, loop/split faces and exact source/history membership. Require
at least one repair that actually changes topology, one no-op, one rejected foreign
lookalike, and a split/merge history case with all paths retained. Compare geometry
and mass using documented tolerances, not approximate topology rebinding.

Verify workspace coupling, multiple outputs, empty/null/duplicate inputs, indices,
overflow, native failures, source/parent disposal, aliasing and SafeHandle release
races. The public integration must prove source preservation where promised and
returned-result usability after receiver disposal. A runtime test must establish
each admitted family, rather than merely inventory its declarations.

Before delivery, preserve all prior IDs/generated files/API/exports; regenerate
from contracts and compile the output. Refresh full inventory and record the
exact admitted/prerequisite/deferred delta. Run full Release/Debug suites, actual
Debug native, cold source build/regeneration, ABI/header/lifetime checks, module
closure, bundled runtime, 14 packages, both clean consumers and unified local
release gates. Bind results to final source/runtime/package hashes. Hosted CI,
signing, push, publication and whole downstream application acceptance remain
separate statuses. Follow [WORKFLOW](WORKFLOW.md); no fixed capability count applies.

## Following batches

After AJ delivery, audit **AK transfer-record/process collections** as the next
adjacent workflow: private transfer process and records, safe recorded entity/shape
snapshots, explicit model-versus-transfer index domains and diagnostic results.
Begin from AJ's fresh exit inventory; freeze exact candidates then. AI's deferred
unsafe root branches and recursive TypedSharings remain excluded until an actual
source-backed safe projection is proved. Do not make them unconditional AK goals.

Then select geometry matrices/workspaces or parser/SDK exclusions from a demonstrated
consumer gap. Keep each useful outcome in a larger coherent batch with its own
delivery checkpoint, rather than starting several incomplete migrations together.
